# Meals-App

A Flutter and Dart meal application designed to demonstrate best practices in state management using Providers and navigation between screens.

## 📱 Overview

Meals-App is a mobile application built with Flutter that showcases a collection of meals with detailed information. The app is structured to help developers learn and understand key Flutter concepts including Provider for state management and navigation patterns.

## ✨ Features

- **Browse Meals**: View a comprehensive list of available meals
- **Meal Details**: Access detailed information about each meal including ingredients and instructions
- **Provider State Management**: Learn how to implement efficient state management using the Provider package
- **Smooth Navigation**: Navigate seamlessly between different screens using Flutter's navigation system
- **User-Friendly Interface**: Clean and intuitive UI for easy meal browsing

## 🛠️ Technologies Used

- **Flutter**: UI framework for building cross-platform mobile applications
- **Dart**: Programming language used with Flutter
- **Provider**: State management solution for managing app state
- **Material Design**: Modern UI components and design patterns

## 🚀 Getting Started

### Prerequisites

Before you begin, ensure you have the following installed:
- Flutter SDK ([Download Flutter](https://flutter.dev/docs/get-started/install))
- Dart SDK (comes with Flutter)
- Android Studio, Xcode, or Visual Studio Code with Flutter extensions

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Asolliman/Meals-App.git
   cd Meals-App
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Run the app**
   ```bash
   flutter run
   ```

## 📂 Project Structure

```
lib/
├── screens/        # App screens (home, details, etc.)
├── providers/      # Provider classes for state management
├── models/         # Data models
├── widgets/        # Reusable custom widgets
└── main.dart       # Entry point of the application
```
